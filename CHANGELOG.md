# Release Notes

## 0.1.0 — modernization baseline

- Renamed the distribution to `freecampus-math` and the import package to
  `fcmath`.
- Added the Mathematics for Quantitative Studies pathway and ten-course
  portfolio.
- Made the versioned curriculum catalog authoritative for stable IDs, outcomes,
  prerequisites, ownership, order, coverage, and generated navigation.
- Added restricted mathematical parsing, policy-driven answer validation, and a
  shared quiz schema with web and notebook renderers.
- Added browser-local progress with export, import, reset, and no raw-answer or
  analytics storage.
- Added deterministic QMD-to-notebook generation, Colab links, curriculum and
  rendered-site validation, and separated CI quality gates.

Earlier experimental scaffold releases used a different project identity and
are not part of the `freecampus-math` version line.
